# Rent With Robyn — brand reference

**Source:** Signage Kit v5 + `@rentwithrobyn` social templates (`rebrand_content.py`).  
**Audience lanes:** **FOR OWNERS** (property management) · **FOR RENTERS** (education only — not legal advice).

## Colours

| Token | Hex | Use |
|--------|-----|-----|
| Ink | `#0d0d0d` | Backgrounds, sidebars, hero blocks |
| Teal | `#00adc0` | Rules, labels, CTAs, footer bands |
| White | `#ffffff` | Type on dark, paper substitute |
| Warm paper | `#faf8f5` | Long-form documents (optional) |

Desk CSS already uses `#111315` / `#00adc0` — close enough; **official forms use `#0d0d0d` + `#00adc0`** when rebuilding PDFs.

## Type

| Role | Font | Weight |
|------|------|--------|
| Social headlines | Montserrat | 800 |
| Print headlines (owner guide) | Playfair Display | 700–900 |
| Body, labels, tables | Montserrat | 500–600 |
| Meta / dates | DM Mono or Montserrat caps | 500 |

## Logos (do not alter)

- **Robyn Graham** — white vector on black; descriptor in teal caps: `REAL ESTATE & PROPERTY MANAGEMENT`
- **Stonehaus Realty Corp.** — official white lockup, bottom-right on client pieces
- **Rent With Robyn** — wordmark on photo posts: `RENT WITH` (white) + `ROBYN` (teal)

Files in `public/branding/logos/` and Signage Kit SVGs for high-res export.

## Layout pattern (social / one-pagers)

1. **Top:** logo (+ portrait or Kate Paterson / Unsplash interior — never imply a specific listing)
2. **Rule + lane:** `RENT WITH ROBYN / FOR OWNERS` or `FOR RENTERS` (teal, tracked caps)
3. **Headline:** one idea, 1–3 lines, white on black
4. **List:** `01` `02` `03` in teal + short practical bullets
5. **Footer band (teal):** 778 926 3481 · robyngraham.ca · **@rentwithrobyn**

## Voice

Warm, direct, practical, local (Langley + Fraser Valley). No invented listings, testimonials, or market stats. Check BC RTA / BCFSA before legal specifics in captions.

## What goes where

| Asset | Brand lane | Template |
|-------|------------|----------|
| Property Owner's Guide PDF | FOR OWNERS | Playfair headline + Stonehaus footer |
| Management / placement agreements | FOR OWNERS | Toolkit `.docx` (Montserrat body) |
| Rental application + screening consent | Neutral / FOR RENTERS | Plain, accessible; no marketing copy |
| RTB / BCFSA forms | Unbranded official | Download only — do not restyle |
| Instagram grid | 50% owners / 50% renters | `preview-grid.jpg` reference |

## Owner vs renter in the desk

- **Owners:** leads, portfolio, placement files, owner guide
- **Renters:** applicants + screening only (consent first; no SIN)
